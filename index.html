Дата біля кожного документа

Підписуйте документ так: «Кошторис на 2026 рік, оприлюднено 12.01.2026». Так легше довести, що строк у 10 робочих днів дотримано.

PDF з текстовим шаром

Скан без тексту не прочитають ні пошукові системи, ні програми екранного доступу. Завантажуйте документ, збережений у PDF з тексту, а скан підпису додавайте окремою сторінкою.

Налаштування ШІ-інструментів

Що створюємо
Робоче середовище з ШІ.
Як
Обираємо Gemini, ChatGPT або Claude і вмикаємо режим перегляду коду.
Навіщо
Бачити сторінку одразу й правити її словами.
Результат
Відкритий чат з увімкненим Canvas або Artifacts.

Gemini

Canvas
  1. Відкрийте gemini.google.com і оберіть найпотужнішу модель.
  2. У полі введення увімкніть «Canvas».
  3. Вставте промт із конструктора.
  4. Перегляньте результат на вкладці «Preview».

ChatGPT

Canvas
  1. Оберіть модель із міркуванням.
  2. Через «+» або «/» увімкніть Canvas.
  3. Вставте промт і попросіть показати код.
  4. Натисніть «Preview», щоб переглянути сторінку.

Claude

Artifacts
  1. Відкрийте claude.ai.
  2. Вставте промт: сторінка з’явиться поруч із чатом.
  3. Правки просіть звичайними словами.
  4. Готову сторінку можна опублікувати й надіслати колегам посиланням.
Перед стартом. Підготуйте в окремому документі назву коледжу, перелік спеціальностей, контакти, кольори та логотип. На сайті використовуйте лише реальні факти. Конструктор просить ШІ ставити заглушку [ДОДАТИ] скрізь, де даних бракує, щоб він нічого не вигадував.

Зберегти

Скопіюйте код із Canvas / Artifacts у файл index.html. Великий сайт збирайте посторінково, кожну сторінку окремим файлом.

Завантажити

Створіть репозиторій на GitHub на акаунт коледжу й завантажте туди файли через «Add file → Upload files».

Опублікувати

На vercel.com натисніть «Add New → Project», імпортуйте репозиторій і запустіть Deploy. За хвилину сайт буде доступний за посиланням.

Під’єднати домен

У налаштуваннях проєкту додайте домен коледжу, наприклад у зоні edu.ua, і пропишіть DNS-записи, які покаже Vercel.
